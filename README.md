# 말랑포커 v2.2 (최종 테스트 빌드)

서로 다른 휴대폰에서 2~5명이 플레이하도록 확장한 무료 가상칩 텍사스 홀덤 웹앱입니다. **브라우저 자동 테스트와 실제 휴대폰 간 테스트는 구분됩니다. 실제 iPhone 5대의 외부 네트워크 연결은 아직 검증되지 않았습니다.**

## 구현된 항목
- 2~5명 방 코드 입장, 방장 권한 게임 진행
- 인원별 블라인드, 텍사스 홀덤 턴 순서, 폴드·체크·콜·베팅·레이즈·올인
- 상세 베팅 입력, 범위 슬라이더, 20칩 증감 버튼
- 미스터 시환킴 카드 딜링·커뮤니티 카드 공개 연출
- 빠른 채팅: 빨리좀 고르세요!, 🥱, 안좋은 한판이네요
- 승패·사이드 팟 정산, 파산 알림, 파산자 관전, 재시작 투표
- 파산 후 새 게임에서 전원 가상칩 1,000개로 재시작

## 배포
GitHub Pages 저장소의 최상위에 ZIP 압축을 푼 내용만 업로드하세요. `index.html`이 최상위에 있어야 합니다. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/(root)`으로 배포합니다. 기존 저장소에 업로드할 때는 같은 파일 이름으로 덮어쓰세요.

## 검증 상태
`node test-engine.js`로 포커 엔진의 카드 족보, 사이드 팟 정산, 2~5인 자동 진행 및 최종 재시작의 기본 테스트를 수행할 수 있습니다. **실제 iOS/Safari 브라우저와 외부 네트워크에서의 5인 P2P 연결은 검증되지 않았습니다.**

- 게스트가 잠시 연결이 끊어지면 방장 연결을 자동으로 재시도합니다. 기존 탭을 새로고침한 뒤 같은 방 코드로도 재접속할 수 있습니다.

## 네트워크
PeerJS(무료 공용 시그널링) 기반이며 방장의 브라우저가 게임 상태를 관리합니다. 방장 브라우저가 종료되거나 네트워크가 제한되면 게임이 중단될 수 있고, 일부 환경에서 실시간 연결이 실패할 수 있습니다. 서버 기반 백엔드나 별도 TURN 인프라가 없는 프로토타입입니다. 환전·현금 베팅 기능은 없습니다.
