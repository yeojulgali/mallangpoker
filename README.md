# 말랑포커 (Mallang Poker)

두 휴대폰에서 서로 다른 장소에서도 즐길 수 있는 **2인 텍사스 홀덤** 웹앱입니다. **가상 칩만 사용**하고, 회원가입이나 서버 API 키 없이 방 코드로 접속합니다.

## 바로 배포하기 (GitHub Pages)
1. GitHub에서 새 공개 저장소를 만듭니다. 예: `mallang-poker`.
2. 이 폴더의 **모든 파일**을 저장소 최상위(root)에 업로드합니다 (`index.html`, `main.js`, `poker-core.js`, `style.css`, `icon.svg`, `manifest.webmanifest`, `service-worker.js`).
3. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch**에서 `main`, `/(root)`를 저장하세요.
4. Pages에 표시된 HTTPS 주소를 두 휴대폰에서 각각 엽니다.
5. 한 명은 **새 방 만들기**, 다른 한 명은 **6자리 코드로 입장하기**를 누릅니다. 방장이 창을 닫으면 게임 세션이 종료됩니다.

네트워크 연결에 [PeerJS Cloud](https://peerjs.com/client/faq)를 사용합니다. 기본 PeerJS Cloud는 무료이며 별도 설정이 필요하지 않지만, 일부 공유기/이동통신 환경에서는 WebRTC P2P 연결이 실패할 수 있습니다. 장기 서비스에는 별도 시그널링/TURN 서버를 권장합니다. 카드와 판 상태는 방장 브라우저 메모리에 보관되며 방장 새로고침 시 복구되지 않습니다.

## 휴대폰 홈 화면에 설치
- iPhone Safari: 공유 → 홈 화면에 추가
- Android Chrome: 메뉴 → 홈 화면에 추가 / 앱 설치

## 게임 규칙
- 2명, 시작 시 각자 가상 칩 1,000개.
- 스몰 블라인드 10 / 빅 블라인드 20, 딜러는 판마다 교대.
- 프리플롭은 스몰 블라인드 먼저, 이후는 빅 블라인드가 먼저 행동합니다.
- 체크 / 콜 / 폴드 / 20칩 단위 레이즈 / 유효 스택 내 최대 베팅을 지원합니다.
- 상대방의 카드와 전체 덱은 상대방에게 전송하지 않습니다. 게임 종료 시 쇼다운에 참여한 카드만 공개됩니다.
- 자금 정산은 간단한 헤즈업 방식이며 정식 포커 토너먼트의 모든 세부 규정을 구현한 것은 아닙니다.
- 금전 배팅·입금·출금 기능이 없습니다.

## 주의
이 앱은 브라우저 간 **서버 없는 P2P** 방식입니다. 방장의 단말기가 게임 상태를 관리하므로 당사자 간 신뢰를 전제로 한 비상업적 2인용 게임입니다. 서비스 운영·부정행위 방지가 필요하면 서버 권위형 아키텍처로 전환하세요.
